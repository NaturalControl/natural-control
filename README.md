# Natural Control

A general-purpose, voice-supervised agent interface for blind people. The initial evaluation will cover connected accounts, unfamiliar websites, and local Mac tasks, alongside VoiceOver and keyboard access. User research and technical validation are pending; Natural Control is a working name.

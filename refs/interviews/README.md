# Interviews
This folder is the central location for all of the interviews that were conducted throughout the project. This allows these interviews to easily be referenced in many documents.
For each interview, there are two or three coresponding filesz here:
- **Interview.md**: The original markdown file that was created during or shortly after the interview containing the a transcript of the conversation or the user's responses
- **Interview.tex**: A tex version of the markdown file generated after the interview from the *.md* file. The content is the same, but the document format is different. This allows the interview to easily be imported into other documents.
- **InterviewFindings.md** (optional): An optional file that lists some findings in the interview. This could either be a summary of the transcript or could contain other notes taken manually by the interviewer.

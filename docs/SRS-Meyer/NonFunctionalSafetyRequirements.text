\begin{itemize}
  \item \textbf{NFR.Sa.1:} A work-stop request shall be audibly acknowledged within STOP\_ACK\_TIME. Measure from the end of the utterance or the key press. Measure dispatch blocking and in-flight reconciliation separately. (H2-b)
  \item \textbf{NFR.Sa.2:} The client shall signal disconnection within CONNECTION\_NOTICE\_TIME. A local sound shall be used if network speech is unavailable. (H3-b)
  \item \textbf{NFR.Sa.3:} While the system is actively working on a task, including planning, browsing, searching, read-only lookups, and executing actions, it shall provide a spoken progress update or report a blocker before IDLE\_PROMPT\_TIME elapses without spoken progress. Time spent awaiting user clarification or approval, or while the task is paused or cancelled, shall not count toward this interval. (H4-c)
\end{itemize}

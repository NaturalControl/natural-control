# Design Documentation

The folders and files for this folder are as follows:

- `SoftArchitecture/MG.tex`: the Module Guide (MG). It covers the anticipated and unlikely changes, the module hierarchy and secrets, traceability to the SRS, and the uses hierarchy.
- `SoftDetailedDes/MIS.tex`: the Module Interface Specification (MIS). It gives the syntax and semantics of each module in the MG.

The built PDFs are in `pdfs/Design/SoftArchitecture/MG.pdf` and `pdfs/Design/SoftDetailedDes/MIS.pdf`.
